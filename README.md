# 서울시 충전소별 잔여 충전량 예측 모델 개발

## 1. 프로젝트 소개

서울시 전기차 충전소의 충전 이력을 분석하여 충전소별 예측 충전량을 산출하고, 분석 결과를 지도에 시각화하는 프로젝트입니다. 충전소별 충전 특성을 파악하고 충전 인프라의 효율적인 운영을 위한 기초자료를 제공하는 것을 목표로 합니다.

## 2. 분석 배경 및 목표

전기차 충전 인프라의 효율적인 운영을 위해서는 충전소별 이용 특성을 파악하고 충전량의 차이를 분석할 필요가 있습니다.

본 프로젝트에서는 충전 시간과 충전량 간의 관계를 분석하고, 충전소별 예측 결과를 공간적으로 비교하여 충전소 운영 및 인프라 개선을 위한 기초자료를 마련하고자 합니다.

## 3. 데이터

- **주요 데이터:** 서울시 소유 전기차충전기 일별 시간별 충전현황(2025년)
- **주요 변수:** 충전소명, 충전시작시간, 충전종료시간, 충전량
- **파생 변수:** 충전시간(분)
- **위치 데이터:** 충전소별 주소 및 위도·경도

## 4. 분석 과정

### ① 데이터 전처리
충전 시작 시간과 종료 시간을 이용해 충전 시간을 계산하고, 충전량의 결측값 및 이상치를 확인하여 분석 데이터를 정제했습니다.

### ② 충전소별 모델 구축
충전소별로 데이터를 구분하고, 충전 시간을 독립변수로 충전량을 예측하는 선형회귀 모델을 구축했습니다.

### ③ 모델 평가 및 예측
학습 데이터와 평가 데이터를 분리하고 MAE, RMSE, 결정계수(\(R^2\))를 활용하여 모델 성능을 평가했습니다. 평가 기준을 충족한 충전소를 대상으로 예측 결과를 산출하고 대표 예측값을 계산했습니다.

### ④ 등급 분류 및 지도 시각화
충전소별 대표 예측값을 기준으로 등급을 분류하고, 충전소의 위도·경도와 결합하여 등급별 색상 지도를 제작했습니다.

## 5. 분석 결과

- 전처리 후 분석 데이터: **215,515개 행**
- 모델 학습 조건을 충족한 충전소: **191개**
- 결정계수(\(R^2\))가 양수인 충전소: **189개**

충전소별 예측 결과를 비교할 수 있도록 대표 예측값을 산출하고, 이를 등급별 지도에 표현했습니다.

## 8. 기대 효과 및 한계

충전소별 예측 결과를 비교하여 충전량의 차이와 공간적 분포를 파악하고, 충전 인프라 운영 효율화를 위한 기초자료로 활용할 수 있습니다.

다만 충전 시간만을 이용한 선형회귀 모델은 시간대별 수요, 충전기 종류, 실제 이용률 등 다양한 요인을 반영하지 못하므로, 향후 추가 변수를 활용한 모델 개선이 필요합니다.
